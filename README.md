# 아미사커 (Army Soccer)

군대 테마의 로블록스 **구기 종목 대잔치** 게임입니다. 한 경기장에서 축구와 배드민턴이 동시에 진행되고, 누구나 두 공을 모두 다룰 수 있습니다. 공 개수는 팀당 4명마다 축구공 1개 + 셔틀콕 1개씩 늘어납니다 (최소 1개씩).

- **축구**: 일반 크기 축구공을 발로 차서(E) 상대 골대에 넣습니다. 골이 나면 다시 킥오프.
- **배드민턴**: 가운데 반투명 네트 너머로 거대 셔틀콕을 **헤딩**으로 넘깁니다. 같은 팀은 3번까지 헤딩할 수 있고, 3번째에 셔틀콕이 빨간색으로 바뀝니다. 4번째 터치는 반칙, 셔틀콕이 땅에 닿으면 그 진영 팀이 실점합니다.
- **자석 드리블**: 축구공에 닿으면 공이 발 앞에 붙어서 따라옵니다 (팀 색 테두리). 다른 선수가 닿으면 뺏깁니다.
- **공은 한 번에 하나만**: 드리블 중에도 헤딩은 되지만, 헤딩하면 축구공을 놓쳐서 공이 앞으로 굴러가고 1.5초 동안 다시 잡을 수 없습니다. "공을 지킬까, 셔틀콕을 살릴까?"
- **무기**: 누구나 소총·저격총·로켓탄을 쏠 수 있습니다. 총알은 사람을 통과하고, 축구공과 셔틀콕을 맞히면 궤적이 바뀝니다. 드리블 중인 공을 맞히면 소유권이 풀립니다. 소총은 약하지만 빠르게 연사, 저격총은 멀리서 세게, 로켓탄은 터지면서 주변 공을 모두 밀어냅니다.
- 경기장(100×70)은 유리벽으로 둘러싸여 있어 스로인·코너킥이 없습니다. 양쪽에 관중석, 위에 대형 점수판이 있습니다.

## 전쟁 모드 (지금 기본값)

`Config.GAME_MODE = "War"` 이면 전쟁 모드, `"Classic"` 이면 위의 4:4 축구 + 배드민턴입니다.

- 경기장 140×90, 팀당 6명 (빈자리는 봇). 공 5개를 **총으로만** 움직입니다. 킥·헤딩·드리블은 없습니다.
- ⚽ 축구공, 🏈 미식축구공: 당구처럼 **구멍 6개**(네 모서리 + 긴 벽 가운데) 중 아무 데나 넣으면, 마지막으로 쏜 선수의 팀이 득점합니다.
- 🏀 농구공: 양쪽 끝 벽 위의 **반투명 링**에 위에서 넣으면 득점 (상대 쪽 링). 링은 농구공만 부딪힙니다.
- 🏐 배구공, 🏸 셔틀콕: **공중 네트**(높이 8~20)를 넘겨 상대 진영 바닥에 떨어뜨리면 득점. 네트 밑으로 빠지면 마지막으로 쏜 팀이 실점합니다. 사람과 축구공은 네트 밑으로 지나다닐 수 있습니다.
- 득점해도 경기는 멈추지 않고, 그 공만 잠시 뒤 다시 나옵니다. 공마다 밀리는 정도와 떨어지는 속도는 `Config.WAR_BALLS`에서 조정합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `E` 길게 눌렀다 떼기 | 축구공 킥 (오래 누를수록 세고 높게) |
| 점프 + 머리에 맞히기 | 셔틀콕 헤딩 (바라보는 방향으로 날아감) |
| `Q` | 돌격 (짧은 대시) |
| 왼쪽 클릭 | 사격 (커서 쪽으로. 공만 맞고 사람은 맞지 않음) |
| `1` / `2` / `3`, `R` | 무기 바꾸기 (소총 / 저격총 / 로켓탄) |

## 경기 규칙

- **알파 분대**(녹색)와 **브라보 분대**(사막색)로 자동 배정, 인원이 적은 쪽에 들어갑니다.
- 5분 경기. 축구 골과 배드민턴 득점이 같은 점수판에 합산됩니다.
- 최소 2명이 모이면 경기가 시작됩니다 (Studio 테스트에서는 1명).
- **테스트용 봇**: 킥오프 때마다 각 팀을 4명까지 봇으로 채웁니다. 실제 플레이어가 들어오면 그만큼 봇이 빠집니다. `Config.BOTS_ENABLED`로 끄고 켭니다.

## 개발 환경 (Rojo)

1. [Rokit](https://github.com/rojo-rbx/rokit) 설치 후 프로젝트 폴더에서 `rokit install` (Rojo 7.4.4 설치)
2. Roblox Studio에 Rojo 플러그인 설치
3. `rojo serve` 실행 후 Studio의 Rojo 플러그인에서 **Connect**
4. Studio에서 플레이 (경기장은 서버가 코드로 자동 생성하므로 맵을 따로 만들 필요가 없습니다)

`.rbxlx` 파일로 바로 만들려면: `rojo build -o ArmySoccer.rbxlx`

## 구조

```
src/
  shared/Config.luau          모든 수치 설정 (경기 시간, 킥 파워, 포격 공 개수, 사격 영향 등)
  server/
    init.server.luau          서버 진입점, 원격 이벤트 생성
    FieldBuilder.luau         경기장/골대/유리벽/관중석/점수판/감시탑 생성
    CollisionGroups.luau      충돌 그룹 (네트는 셔틀콕만 막음)
    PlayerService.luau        팀 배정, 헬멧, 리더보드, 킥오프 배치
    BallService.luau          축구공, 킥 처리, 골 판정
    ShuttleService.luau       거대 셔틀콕, 네트, 헤딩, 3번 터치 규칙, 착지 판정
    WarService.luau           전쟁 모드 공 5종, 구멍·링·네트 득점 판정
    WeaponService.luau        무기 (소총·저격총 즉시 명중, 로켓탄 비행·폭발)
    BotService.luau           테스트용 봇 (각 팀 4명까지 채움, 셔틀콕 헤딩·드리블·슛)
    MatchService.luau         경기 흐름 (대기 → 카운트다운 → 경기 → 종료)
  client/
    init.client.luau          클라이언트 진입점
    HUD.luau                  점수판, 타이머, 안내 문구, 킥 게이지, 조작 안내
    Controls.luau             입력 처리 (킥 차징, 돌격, 무기 바꾸기·사격)
```

밸런스 조정은 `src/shared/Config.luau`의 값만 바꾸면 됩니다. 예: `SHUTTLE_DIAMETER`(셔틀콕 크기), `PLAYERS_PER_BALL`(공 1개당 팀 인원), `SHUTTLE_GRAVITY_SCALE`(셔틀콕 낙하 속도), `HEADER_UP_SPEED`(헤딩 높이), `NET_HEIGHT`(네트 높이).

모든 판정(킥 거리, 쿨다운, 명중)은 서버에서 검사하므로 클라이언트 조작으로 능력을 남용할 수 없습니다.
