# 아미사커 (Army Soccer)

군대 테마의 로블록스 축구 게임입니다. 두 분대가 축구 경기를 하는데, **병과**에 따라 특수 능력이 있습니다.

- **전차병**: 포격을 하면 포탄 한 발에 공 여러 개(기본 3개)가 조준 지점 주변으로 **포물선을 그리며** 날아갑니다. 이 보너스 공도 골대에 들어가면 득점입니다.
- **소총수**: 날아가는 공을 쏴서 맞히면 **궤적이 살짝 바뀝니다**. 상대 슛을 빗나가게 하거나 우리 슛을 보정할 수 있습니다.
- **골키퍼**: 3초 동안 움직이지 못하고 충전한 뒤 **스페셜 슛**(빨간 공)을 상대 골문으로 날립니다. 이 공은 상대 골키퍼와 모든 선수를 통과하므로, 상대 소총수 사격이나 전차 포탄 공으로 궤적을 바꿔야만 막을 수 있습니다. 골키퍼는 자기 페널티 박스 밖으로 나갈 수 없습니다.

### 진영 규칙
필드 선수는 하프라인 벽에 막혀 자기 진영에만 있습니다. **자기 진영에서 적 방향으로 공을 찬 선수만** 8초 안에 하프라인을 넘어 공격하러 갈 수 있고, 자기 진영으로 돌아오면 다시 막힙니다. 그래서 항상 수비수가 남습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `E` 길게 눌렀다 떼기 | 킥 (오래 누를수록 세고 높게) |
| 마우스 클릭 / `F` | 병과 스킬 (마우스 위치로 조준) |
| `Q` | 돌격 (짧은 대시) |
| 좌측 하단 버튼 | 병과 선택 (소총수 / 전차병 / 골키퍼) |

모바일과 게임패드는 화면 버튼(킥 / 스킬 / 돌격)이 자동으로 생기고, 스킬은 화면 중앙을 조준합니다.

## 경기 규칙

- **알파 분대**(녹색)와 **브라보 분대**(사막색)로 자동 배정, 인원이 적은 쪽에 들어갑니다.
- 5분 경기. 메인 공(흰색)이 들어가면 득점 후 양 팀이 제자리로 돌아가 다시 킥오프합니다.
- 보너스 공(주황색)이 들어가면 득점만 되고 경기는 계속됩니다. 보너스 공은 20초 뒤 사라지며, 최대 9개까지 존재합니다.
- 전차병과 골키퍼는 팀당 1명까지만 고를 수 있습니다.
- 최소 2명이 모이면 경기가 시작됩니다 (Studio 테스트에서는 1명).

## 개발 환경 (Rojo)

1. [Rokit](https://github.com/rojo-rbx/rokit) 설치 후 프로젝트 폴더에서 `rokit install` (Rojo 7.4.4 설치)
2. Roblox Studio에 Rojo 플러그인 설치
3. `rojo serve` 실행 후 Studio의 Rojo 플러그인에서 **Connect**
4. Studio에서 플레이 (경기장은 서버가 코드로 자동 생성하므로 맵을 따로 만들 필요가 없습니다)

`.rbxlx` 파일로 바로 만들려면: `rojo build -o ArmySoccer.rbxlx`

## 구조

```
src/
  shared/Config.luau          모든 수치 설정 (경기 시간, 킥 파워, 포격 공 개수, 사격 영향 등)
  server/
    init.server.luau          서버 진입점, 원격 이벤트 생성
    FieldBuilder.luau         경기장/골대/벽/모래주머니/감시탑 생성
    PlayerService.luau        팀 배정, 병과 선택, 헬멧, 리더보드, 킥오프 배치
    BallService.luau          공 관리, 킥/사격/포격 처리, 골 판정
    ZoneService.luau          진영 규칙(하프라인 돌파), 골키퍼 구역, 충돌 그룹
    MatchService.luau         경기 흐름 (대기 → 카운트다운 → 경기 → 종료)
  client/
    init.client.luau          클라이언트 진입점
    HUD.luau                  점수판, 타이머, 안내 문구, 킥 게이지, 병과 선택 UI
    Controls.luau             입력 처리 (킥 차징, 스킬 조준, 돌격)
```

밸런스 조정은 `src/shared/Config.luau`의 값만 바꾸면 됩니다. 예: `TANK_BALLS`(포탄당 공 개수), `TANK_SPREAD`(흩어짐), `RIFLE_NUDGE`(소총 명중 시 궤적 변화량).

모든 판정(킥 거리, 쿨다운, 명중)은 서버에서 검사하므로 클라이언트 조작으로 능력을 남용할 수 없습니다.
