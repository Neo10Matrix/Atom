# 아미사커 개발 계획

## 0. 개발 방식 (가장 효율적인 방법)

**결론: 집 컴퓨터에 Claude Code + Rojo + Roblox Studio MCP를 같이 쓴다.**

| 방식 | 장점 | 단점 |
| --- | --- | --- |
| 코드 복사·붙여넣기 | 설치가 필요 없음 | 파일이 많아지면 실수가 잦고 버전 관리가 안 됨 → **비추천** |
| **Rojo** (현재 구조) | 유니티처럼 코드를 파일로 관리, 저장하면 Studio에 자동 반영, Git으로 기록 | 처음 설치가 한 번 필요 |
| **Studio MCP** | 집 컴의 Claude Code가 열려 있는 Studio를 직접 읽고 수정·테스트 | 집 컴에서만 가능 (클라우드 세션에서는 불가) |

- 코드(스크립트)는 **Rojo**로 동기화하고, 맵 배치 확인이나 플레이 테스트는 **Studio MCP**로 Claude Code가 직접 돌려본다.
- Studio의 Assistant 설정에 있는 MCP "Quick connect"에서 Claude Code를 연결할 수 있다 (Roblox 공식 문서: https://create.roblox.com/docs/en-us/studio/mcp).

### 집 컴 준비 순서
1. Roblox Studio 설치
2. Git, VS Code, [Rokit](https://github.com/rojo-rbx/rokit) 설치
3. `git clone` 후 프로젝트 폴더에서 `rokit install` (Rojo 설치)
4. Studio에 Rojo 플러그인 설치 → `rojo serve` → 플러그인에서 Connect
5. Claude Code 설치 → Studio MCP 연결
6. Studio에서 Play로 테스트

## 1단계: 새 규칙 반영
- [x] **골키퍼 병과** 추가 (팀당 1명)
  - 스페셜 슛: 길게 차징 (예: 3초), 차징 중 이동·점프 불가
  - 스페셜 공은 상대 골키퍼와 충돌하지 않음 (CollisionGroup으로 통과)
  - 소총수 사격·전차 포탄 공에만 궤적이 바뀜 → 막을 수 있는 유일한 수단
  - 쿨다운 길게, 차징 중 이펙트(빛·소리)로 상대에게 미리 알림
- [x] **진영 제한**: 하프라인 벽(충돌 그룹으로 선수만 막음), 자기 진영에서 적 방향으로 킥한 선수만 8초 안에 통과 가능
- [x] **골키퍼 구역**: 페널티 박스 투명 벽 (골키퍼만 막힘)
- [x] 벽으로 둘러싼 경기장 (스로인·프리킥·코너킥 없음) — 이미 구현됨
- [x] 전차병 포물선 다중 공, 소총수 궤적 변경 — 이미 구현됨

## 2단계: 플레이 테스트 & 밸런스
- [x] 테스트용 봇 (각 팀 4명까지 채움, `Config.BOTS_ENABLED`)
- 혼자 테스트 → Studio의 "로컬 서버 + 플레이어 2~4명"으로 팀전 테스트
- 조정 대상: 스페셜 슛 차징 시간, 소총 궤적 변화량, 포탄 공 개수/쿨다운, 진영 규칙

## 3단계: 인기 게임 요소 넣기
- 짧고 빠른 경기 (3~5분), 대기 없이 바로 입장
- 화려한 스킬 연출 (스페셜 슛 이펙트, 포격 폭발, 카메라 흔들림)
- 수집 요소: 병과 스킨, 헬멧/위장복 꾸미기
- 랭크전 / 시즌 보상
- 모바일 버튼 UI 다듬기 (로블록스 유저 상당수가 모바일)

## 4단계: 출시 준비
- 아이콘, 썸네일, 소개 문구
- 게임패스 (스킨, 이펙트 — 능력치 판매는 피함)
- 그룹 생성, 소규모 테스트 공개 → 피드백 → 정식 공개

## 현재 방향: 구기 종목 대잔치
한 경기장에 여러 종목의 공이 동시에 있다. 축구공은 일반 크기, 셔틀콕은 거대하다. 종목 선택 없이 누구나 모든 공을 다룬다.
공 개수는 팀당 4명마다 종목별 1개씩 늘어난다 (4:4 → 축구공 1 + 셔틀콕 1, 8:8 → 2 + 2).

| 종목 | 공 | 규칙 | 상태 |
| --- | --- | --- | --- |
| 축구 | 축구공, 일반 크기 (인원별) | 발로만 (E 킥). 골대에 넣으면 득점 → 킥오프 | 구현됨 |
| 배드민턴 | 거대 셔틀콕 (인원별) | 가운데 반투명 네트. 헤딩으로 넘김. 팀당 3번, 3번째 빨간색, 땅에 닿으면 실점 | 구현됨 |
| 미식축구 | 미식축구공 | 손으로 들고 뛰기/던지기? 엔드존 터치다운? | 규칙 미정 |

- **자석 드리블 + 소유권**: 공에 닿으면 발 앞에 붙어 따라옴, 닿으면 뺏기 — 구현됨
- **공은 한 번에 하나만**: 드리블 중 헤딩하면 축구공을 놓치고 1.5초 동안 못 잡음 — 구현됨

- **경기장 개편**: 플러그인 경기장(`reference/`) 토대로 100×70, 유리벽, 관중석, 대형 점수판 — 구현됨

## 확정된 세부 규칙
- 진영 돌파는 공을 찬 **그 선수만** 가능 (팀 전체 X)

- 스페셜 슛은 소총 사격과 전차 포탄 공 둘 다로 궤적이 바뀜
